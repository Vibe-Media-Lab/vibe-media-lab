## 발생한 이슈 & 해결

### 1. tsconfig extends 경로 문제
- **문제**: `@repo/typescript-config/base.json` 찾지 못함
- **해결**: 각 패키지에 `@repo/typescript-config` devDependency 추가

### 2. NodeNext moduleResolution
- **문제**: import 경로에 `.js` 확장자 필요
- **해결**: 모든 import에 `.js` 확장자 추가

### 3. Supabase 타입 오류
- **문제**: insert/update 시 타입 불일치
- **해결**: `as never` 캐스팅으로 임시 해결

### 4. 환경변수 미설정 빌드 에러
- **문제**: Supabase URL/Key 없이 빌드 시 프리렌더링 실패
- **해결**: try-catch로 감싸고 graceful fallback

### 5. Google OAuth 미설정
- **문제**: "Unsupported provider" 에러
- **해결**: 일단 이메일 로그인으로 진행 (Google OAuth는 선택사항)
