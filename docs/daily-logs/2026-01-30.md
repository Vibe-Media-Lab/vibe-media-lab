### 8. Phase 5.9: 6-Act Zootopia Protocol 적용 (밤)

kids 프로젝트의 Story Architect/Writer 방식을 LLM 프롬프트에 적용.

**타입 확장** (`packages/shared/src/types.ts`):

```typescript
// 캐릭터 프로필
interface KidsCharacter {
  name: string
  role: 'protagonist_a' | 'protagonist_b' | 'villain' | 'supporting'
  species: string           // 예: "bunny", "bear"
  personality: string
  visualDescription: string // 이미지 생성용 영어 묘사
  voiceId?: string
  speakingStyle?: string
}

// 6-Act Zootopia Plot
interface KidsZootopiaPlot {
  hook: { title, summary, narration, visualPrompt, emotion }
  duo: { ... }
  journey: { ... }
  twist: { ... }
  action: { ... }
  resolution: { ... }
}

// 24가지 감정 타입
type ShotEmotion = 'hopeful' | 'curious' | ... | 'joyful'

// Enhanced Shot
interface KidsShot {
  actKey?: ActKey
  emotion?: ShotEmotion
  voiceId?: string
  speechStyle?: string
  speaker?: string
  cameraMovement?: 'static' | 'pan' | 'zoom-in' | 'zoom-out' | 'tracking'
}
```

**상수 추가** (`packages/shared/src/constants.ts`):
- `KIDS_VOICE_PROFILES` - 나레이터/주인공/조연별 음성 프로필
- `KIDS_EMOTION_TTS_PARAMS` - 감정별 TTS 파라미터
- `KIDS_ZOOTOPIA_ACTS` - 6-Act 정의

**LLM 프롬프트 개선** (`llm-service.ts`):
- `generateStory()`: Zootopia Protocol 프롬프트, 캐릭터 설계 원칙
- `generateScript()`: 감정/음성/카메라 무브먼트 포함

**Preview 업데이트** (`generation-review-step.tsx`):
- Enhanced 형식 감지 및 캐릭터/세계관/6-Act 구조 표시
